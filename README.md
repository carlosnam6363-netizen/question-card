## ⚡ PC ↔ 스마트폰 실시간 동기화 (10초 이내 보장)
- **실시간 양방향 푸시:** PC에서 외워서 삭제(휴지통 이동)하거나 중요(★) 표시를 누르면, 스마트폰에서도 **1초 이내(평균 0.5초)**에 자동으로 화면이 갱신됩니다.
- **반대 방향도 동일:** 출퇴근길 스마트폰에서 학습한 내용도 PC 화면에 즉시 동기화됩니다.
- **오프라인 및 상태 보존:** 한쪽 기기가 꺼져 있어도 클라우드 Retained 브로커와 LocalStorage에 최신 상태가 보존되어, 다른 기기를 켜는 즉시 최신 상태를 불러옵니다.
- **비공개 룸 코드:** 상단의 `[실시간 동기화 중]` 뱃지를 누르면 나만의 고유 동기화 채널 코드를 변경할 수 있습니다. (기본값: `carlosnam6363-question-card`)

## 📱 스마트폰에서 앱처럼 사용하는 꿀팁 (PWA)
1. 스마트폰 브라우저(Safari / Chrome / Samsung Internet)로 위 주소에 접속합니다.
2. 브라우저 메뉴에서 **[홈 화면에 추가]**를 누릅니다.
3. 바탕화면에 바로가기 앱 아이콘이 생성되어, 인터넷 주소창 없이 **스마트폰 전용 어플**처럼 쾌적하게 학습할 수 있습니다.

## 🌟 핵심 기능
- **단원별 필터링:** 1단원 보일러설계·구조(230문항), 2단원 연소·관리(135문항), 3단원 계측·제어(58문항), 실무기출종합(242문항)
- **외운 문제 삭제 & 휴지통 원복:** 이미 외운 문제는 삭제하여 리스트에서 제외하고, 언제든 휴지통에서 개별/전체 복구 가능
- **4대 심화 학습 탭:**
  1. 📖 **상세 풀이 & 핵심 포인트:** 계산 공식 및 단계별 풀이
  2. ⚡ **암기 공식 & 단순화 꿀팁:** '모폭브데파리', '본연부', '탄가산피일염' 등 두문자 암기법
  3. 🔍 **필수 용어 사전:** 시험 문제에 나오는 전문 공학 용어 해설
  4. 🔄 **유사 기출 & 변형:** 출제 변형 유형 및 함정 비교
- **키보드 단축키 (PC):**
  - <kbd>Space</kbd>: 정답 확인
  - <kbd>←</kbd> / <kbd>→</kbd>: 이전 / 다음 문제
  - <kbd>Delete</kbd>: 외웠어요(삭제)
  - <kbd>S</kbd>: 중요(★) 표시
  - <kbd>1</kbd> ~ <kbd>4</kbd>: 풀이/암기팁/용어/유사문제 탭 전환
- **🔊 스마트 음성 읽기 (TTS):** 문제와 정답을 귀로 들으며 반복 학습 지원
